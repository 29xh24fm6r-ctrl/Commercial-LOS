# PR 7 — Multi-Profile Certification

## Result

The repository certification corpus covers six materially different operating
models:

1. single authorized officer;
2. combined lender/underwriter with independent approval;
3. fully segregated approval;
4. committee approval;
5. hybrid amount/risk routing; and
6. governed policy-version migration.

Each profile is exercised for a permitted action; missing, insufficient, and
expired authority; relationship exposure; product/risk/geography/industry
scope; policy exceptions; role combination; durable evaluation evidence; audit
and timeline reconciliation; and honest combined-duty disclosure.

Committee profiles additionally prove quorum, approvals, abstention treatment,
recusal, duplicate-identity rejection, declines, and committee authority limits.
Non-committee profiles prove that committee evidence is not fabricated or
silently required. Hybrid certification proves both threshold and risk routes.

Direct Dataverse bypass protection is pinned to the committed synchronous
server plug-in registration and its unit-test corpus. This evidence does not
claim production registration.
